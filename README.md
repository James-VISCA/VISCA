# VISCA Solutions - AI-Powered Business Automation

A modern, responsive website for VISCA Solutions, showcasing AI automation services and solutions.

## 🚀 Features

- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop)
- **Modern UI/UX**: Clean, professional design with interactive elements
- **SEO Optimized**: Complete meta tags, Open Graph, and Twitter Cards
- **Performance Focused**: Optimized images, loading states, and smooth animations
- **Analytics Ready**: Google Analytics integration with custom event tracking
- **Interactive Elements**: Shimmer effects, hover animations, and smooth transitions

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript**: Interactive features and analytics integration
- **WebP Images**: Optimized image formats for better performance

- Google Analytics integration

## 🚀 Getting Started

1. Clone the repository
2. Replace `GA_MEASUREMENT_ID` with your Google Analytics ID
3. Update domain references in meta tags
4. Deploy to your hosting platform
